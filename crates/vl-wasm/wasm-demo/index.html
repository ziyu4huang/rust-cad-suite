XLS-generated Verilog, verified independently — in this browser

Google XLS (DSLX → IR → Verilog HLS) ships a pluggable VerilogSimulator interface whose only built-in implementation is Icarus Verilog; Verilator appears upstream only as a doc example. The cards below take XLS-generated Verilog from this repo's oracle-recorded corpus and simulate it with rverilator-wasm — an independent, clean-room check that does not trust XLS's own high-level (DSLX/JIT) evaluation. stdout is compared byte-for-byte against the Verilator-recorded expectation.
