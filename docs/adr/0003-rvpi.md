# ADR-0003: rVPI — Rust 原生 VPI 結構等價介面

日期:2026-10-23 · 狀態:Accepted(slice 1 落地) · 流程:planner 出案 → 對抗審(4×P1 修入)→ 合成 → 實作

## 背景與目標

C-VPI(IEEE 1364-2005 §23-26)的測試與生態依賴 C ABI(`vpi_user.h`、用戶
C 代碼鏈入模擬器);本專案 clean-room 零 C 鏈接,C ABI 兼容層不在目標。
**目標 = 結構等價,非逐字移植**:句柄/屬性/值讀寫/回調/時間/模擬控制,
用 Rust 慣用架構(trait/enum/closure/零 unsafe)重寫,能力面與架構形狀
對齊 C-VPI。

## 決策

### D1 — 句柄 = 凍結名表索引(`VpiHandle(u32)`),不用 token/epoch、不用借用
- 事實:runtime 無 `cells.remove`(9 個 insert 站點全在 build 內)、
  union-find 在 instance elab 後凍結 → **懸垂不可能**,epoch 計數是死 API。
- 表 = 全部 cell(union-find 正典化)+ 每記憶體字 + 合成 Module 條目
  (根=top 模組名),按名排序 → id 確定(VCD id 排序先例)。
- `find()` 會路徑壓縮需 `&mut`(對抗審 B 項)→ 讀 API 走非變異 `find_follow`。
- 跨-Sim 句柄誤用 = 錯物件非記憶體不安全;文檔聲明 per-Sim。

### D2 — 回調 = `Box<dyn FnMut(&mut Sim, &CbInfo>)` 存於 Sim,take-drain 觸發
- 觸發點對映(切片 1):StartOfSimulation=run() 入口;ValueChange=寫點記入
  `pending_vc`(BTreeMap 折疊,與 VCD pending 同語義)+ 三個排水點
  (run 入口 settle 後 / NBA 區 settle 後 / 槽靜默);AfterDelay=時間推進
  `now=t` 後、delayed 進程恢復前(timer map 派發);EndOfSimulation=兩個
  Ok 出口(不含 SimError 路徑)。ReadWrite/ReadOnlySynch=切片 2。
- 重入契約:回調內 put_value 走阻塞賦值同路徑(assign_lvalue→settle→
  wake_check),寫入進下一輪 pending,結構上無重入;級聯預算 10k → SimError。
- ValueChange 排水點**不在每條 BAssign 後**(對抗審 C 項:exec_one 內觸發
  過度急切)——槽邊界排水 + BTreeMap last-wins = 寫爆發摺疊。

### D3 — crate 佈局 = `vl-sim::vpi` 模組(非獨立 crate)
獨立 crate 會逼 `vl-sim` pub 調度器內臟(約束 M9/tier-B 重構)或造成
types-crate ↔ impl-crate 環;回調存儲必須住在 Sim(觸發點在 run()/settle() 內)。
寫成 facade(不向上依賴 interp 內部),未來拆分=檔案搬移+re-export。

### D4 — put_value(NoDelay) = 阻塞賦值同路徑
立即寫 + settle + wake_check + VC 排水;ReadOnly 區拒收是切片 2(region 旗標)。
Transport/Inertial 延遲模式 = 切片 2(本事件模型無脈衝消除,兩模式將同義,
已登記分歧)。force/release 不做(PLAN 已列聲明外)。

## 非目標(圍欄)
`extern "C"` ABI 層、vpiHandle 線格式、acc_/tf_ 舊 PLI、save/restore、
字串 cell、>64-bit 值(等多 limb ADR)、`--vpi-script` CLI 旗標
(庫優先;測試直接驅動 Sim)。

## 驗證(兩條路徑一個真相 + 內部交叉)
1. `vpi_gate`(8 測):句柄/屬性/children、觸發序、NBA 可見性、put 阻塞
  傳播、x 拒 Int、記憶體字讀寫/整體寫拒、寫爆發摺疊、remove_cb。
2. **two-paths-one-truth**:VPI AfterDelay 取樣渲染行 == corpus 44_lfsr
  oracle 錄製輸出(零手寫期望)。
3. **rVPI×VCD 內部交叉**(vl-difftest tests):同一次 run 的寫點 VC 軌跡 vs
  槽邊界 VCD dump,變化集一致(t=0 快照行除外=初始轉儲非變化事件)。
4. 4-state 只走單測(X-policy D1);既有閘全數不動。

## 分歧登記(REGISTRY 同輪)
D12 VC 排水語義(槽邊界摺疊 vs C 同步逐次)、D13 EndOfSimulation 不在
SimError 觸發、D14 Finish/Stop 合流(同 $stop 既有行為)、D15 Transport≡
Inertial(切片 2)。
